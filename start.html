安装与登录

方式一（推荐）：向管理员或 QQ 群获取「祈愿龙珠」客户端整合包，解压后用启动器指向 .minecraft 目录，选 Forge 1.20.1 启动即可。

方式二（自己组装）：装 MC 1.20.1 + Forge 47.4.10，把全部模组放入 mods 文件夹。核心模组为 dragonminez-…-client.jar（管理员提供，版本必须与服务端一致）。服务端专属组件（QiyuanOps、QyPeak 等）客户端不需要安装。

内存建议：分配 4–6 GB（-Xmx4G 或更多）。

首次登录：多人游戏 → 添加服务器 → 地址填上方地址 → 进入后 /register 密码 密码 注册 → 之后每次 /login 密码 → 修改密码 /changepassword 旧密码 新密码。

⚠ 离线服下用户名+密码就是账号，请勿使用弱密码，不要把账号借给别人。

推荐的第一小时

1. 完成新手教学前几课，攒下第一批 TP

2. 按 O → 领取修行签到（100 祈子）

3. 按 V 打开面板，把 TP 加到属性上（加点提升等级与战力）

4. 按 O → 官方路径点传送 → 去找武天老师（龟仙屋）或孙悟空（悟空的家）拜师学技能

5. 学会「飞行」后按 F 起飞，开启看哪飞哪的龙珠世界

6. 去 O → 地下城 进入无尽厅堂，打怪熟悉战斗并赚祈子

7. 有余力后打开 V → 剧情任务树，从第一章开始推进

界面小知识

· 屏幕上的 气（KI）/ 体力（STM）/ 生命（HP） 条是 DMZ 战斗核心：气不够放不出技能，体力不够无法冲刺格挡。

· 吃东西回复的不只是饱食度，还会按比例回复生命/气/体力——熟牛肉等高饱食度食物性价比更高。

· 按 V 面板里有「属性 / 技能 / 形态 / 任务」多个页签，转生按钮也在这里。
