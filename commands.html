指令速查

Command Reference

只列普通玩家可用的指令。<> 为必填、[] 为可选；标 ⚠ 的是容易踩坑的点。服务器功能优先推荐按键（O / V / X / H）而非指令。

登录与账号

指令说明
/register <密码> <密码>首次进服注册
/login <密码>每次进服登录
/changepassword <旧> <新>改密码

自我查询

指令说明
/dmzstats查看自己的六维属性
/dmzpoints查看可分配的训练点
/dmzskill查看已学技能
/dmztech查看已学的气弹/打击技
/dmzform查看已解锁形态
/dmzeffect查看身上的 DMZ 效果
/dmzalignment查看阵营值（善/中立/恶）
/dmzquest list / info <id> / track <id|none>任务进度/详情/追踪 ⚠ 任务 ID 里的 : 要写成 .，如 saiyan_saga.1
/money（/balance、/bal）查祈子余额；/money top 排行

外观

指令说明
/dmztail grow / cut长出/剪掉尾巴
/dmzhair resync / reset发型同步 / 重置默认

组队 / 融合

指令说明
/dmzparty查看队伍
/dmzparty invite <玩家>邀请
/dmzparty accept（不兼容时 accept confirm）接受邀请
/dmzparty leave / kick <玩家> / disband离开（队长离开=解散）/ 踢人 / 解散
/dmzparty pvp队内 PvP 开关
/dmzfusion finish提前结束自己的融合

地下城与巅峰赛

指令说明
/qyd enter进入无尽厅堂（或按 O 键）
/qyd where查看自己在副本中的位置
/qyd leave离开副本（主动离开不记冷却）
/qyd list / info副本列表/信息
/peak queue / leave / top / info巅峰赛排队/退出/排行榜/个人信息（别名 /dianfeng、/df）
/qya queue <solo|duo|trio>巅峰赛按赛制排队
/qya leave / status / rating退出排队 / 状态 / 查自己隐藏分
/qya party invite <玩家> / accept / list巅峰赛组队

转世

指令说明
/reincarnate查看转世资格与说明
/reincarnate confirm确认转世 ⚠ 不可逆，属性按转数保留规则清减（见 死亡与转世）
/rules查看服务器规则

传送 / 家园 / 地皮

指令说明
/spawn回主城
/home set / /home设置/回家
/tpa <玩家> / /tpa here <玩家>请求传送到对方 / 叫对方过来
/back回到上个位置（部分场景）
/plot auto领取家园地皮
/plot home回地皮
/plot visit <玩家> / add / trust / deny / remove参观 / 授权建造 / 永久共管 / 拉黑 / 移除授权
/plot merge / unlink / info合并 / 拆分 / 查看地皮

经济 / 交易

指令说明
/pay <玩家> <金额>转账
/ah拍卖行；/ah sell <起拍价> [一口价] 上架手持
/trade <玩家>面对面交易（对方 accept）
/bounty set <玩家> <金额> / list / accept悬赏
/qysell hand / all出售带「价值」行的物品（手持整组 / 主背包全部）

社交 / 其他

指令说明
/pm <玩家> <消息>私聊；/pm clear 清空
/mail send <玩家> <消息> / read离线邮件
/nickname <名字>（/nick）改自己昵称
/afk挂机状态
/playtime [玩家] / top游玩时长与排行
/kit list / /kit <名称>礼包列表 / 领取（如有限时礼包）
/crates查看抽奖箱钥匙
/planet info [星球] / unstuck星球信息 / 星球卡死自救
/help [页码]命令帮助
/msg <玩家> <消息>私聊（CMI 侧）
